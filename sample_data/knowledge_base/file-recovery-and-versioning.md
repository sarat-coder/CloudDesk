# File Recovery and Versioning

## The Trash

When you delete a file in CloudDesk, it moves to the **Trash** and is kept for **30 days** before permanent deletion. To restore a file:

1. Go to **Files → Trash**.
2. Locate the file and click **Restore**.
3. The file is returned to its original location.

## File Versioning

CloudDesk keeps up to 30 versions of each file. Each time you save a modified file, a new version is created. To access previous versions:

1. Right-click the file and select **Version History**.
2. A list of versions with dates and authors is shown.
3. Click **Restore** next to any version to make it the current version.
4. The previously current version is not deleted — it becomes version N-1.

## Missing Files: Checklist

If files are missing from a folder, check:

1. **Trash**: Someone may have deleted them (see above).
2. **Search**: Use the global search bar to search by filename.
3. **Activity Log**: Go to the folder → **More Options → Activity Log** to see who made changes and when.
4. **Shared Link Expiry**: If you accessed the files via a shared link, the link may have expired.

## Recovering Files Deleted More Than 30 Days Ago

CloudDesk holds backups for **90 days** (Business/Enterprise) or **14 days** (Free/Pro). If your file was permanently deleted:
1. Submit a support ticket with the exact file path and approximate deletion date.
2. Our team will check backups and restore the file if it falls within the backup retention window.

This process may take up to 48 hours.

## Contacting Support for Data Loss

For urgent data loss situations (e.g., files needed within hours for a client meeting), contact support via **live chat** and mark the ticket as **High Priority**. Provide:
- Full file path of missing files
- Approximate date and time files were last seen
- Number of files affected
- Business impact (e.g., client presentation in 2 hours)

CloudDesk support will escalate data loss tickets to the Data Recovery team.
